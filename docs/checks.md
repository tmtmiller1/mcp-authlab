## Disputed checks

These stay MUST because the spec says MUST. A [policy file](grading.md#policy-files) can downgrade them.

**ORIG-01** Request with a hostile Origin header is refused. The transports spec says servers MUST validate Origin to stop DNS rebinding. Operators point out that non-browser clients never send Origin, so a server that only checks Origin when it is present is also defending the browser case. This check sends a hostile Origin, so a server that validates when present still passes; the pushback is from operators who skip the header entirely because their clients are CLIs.

**VER-01** Unsupported MCP-Protocol-Version is refused with 400. The transports spec says a server MUST respond 400 to an unsupported MCP-Protocol-Version. Operators prefer to answer with the newest version they support so older clients keep working. The spec text is clear, so this stays MUST; use a policy downgrade if your organisation accepts version tolerance.
