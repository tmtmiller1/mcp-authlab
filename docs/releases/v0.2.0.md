mcp-authlab checks whether an MCP server refuses the tokens it should refuse. It logs in to the server's authorization server, mints real tokens, and then tries the resource server with an unsigned token, a token issued for another service, and a session ID with no token behind it. Every finding cites the line of the spec it enforces. Python standard library only.

## Highlights

- **Login.** `mcp-authlab login <url>` runs the real authorization code flow with PKCE, registers a client or uses `--client-id`, and stores tokens in `~/.config/mcp-authlab/tokens.json` (mode 0600). `scan` picks them up and refreshes them when they expire, so the token and session checks run for anyone who can sign in.
- **Foreign-audience token.** Login also mints a token for a different resource, which is what makes the audience-binding check (TOK-03) real instead of synthetic.
- **Authorization server checks, ASF-01 to ASF-06.** PKCE required, wrong verifier refused, wrong `redirect_uri` refused, tokens bound to the requested resource, refresh tokens rotate, HTTPS and `iss` everywhere. A login is two sign-ins, three if the server revokes codes after a failed exchange, four with `--thorough`.
- **Scope step-up, SCOPE-01.** A tool call the token can't make should get a 403 with `error="insufficient_scope"`, a `scope` hint and `resource_metadata`. `--tool` picks the tool; the default is a read-only one.
- **Conformance level.** The headline is now Unsafe, Non-conformant, Conformant with warnings, or Conformant, read from the spec's MUST and SHOULD language. The letter grade stays for `--fail-under`. [docs/grading.md](../grading.md) has every weight and a worked example.
- **Coverage line.** Each report starts with how many checks ran and which critical ones didn't. A critical check that times out or gets disconnected caps the grade at C.
- **Policy files.** `--policy authlab.toml` sets `fail_under`, `ignore` and `downgrade` for a team. Ignored checks still run and print. ORIG-01 and VER-01 carry a note on why operators dispute them; they stay MUST.
- **SARIF and a schema.** `--format sarif` feeds GitHub code scanning. [docs/report.schema.json](../report.schema.json) describes the JSON report.
- **Registry.** [registry/](../../registry) lists five public MCP endpoints with a script that scans them unauthenticated and writes a summary table. Results from today's run are checked in.

Also in this release: the reference fixture has its own authorization server, so login and scan run offline in the test suite (86 tests, Python 3.11 to 3.13); `WWW-Authenticate` parsing follows the RFC 9110 grammar; `mcp-authlab logout`; tokens and codes are redacted from `--requests` output. Full list in the [changelog](../../CHANGELOG.md).

## Install

```
pipx install mcp-authlab
```

## Try it without a server

```
git clone https://github.com/tmtmiller1/mcp-authlab && cd mcp-authlab
scripts/demo.sh passthrough
```

This starts the bundled reference server with token validation broken, logs in to it without a browser, and scans it.
